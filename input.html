성적 입력 및 수정

직접 입력을 통해 학생 한 명의 성적을 추가로 입력할 수 있습니다.
엑셀 업로드를 통해 일괄적으로 성적을 저장할 수 있습니다.

입력 가이드

  • 학번 필수 입력
  • 18개 과목 점수(0~100) 및 달성도(상, 중, 하)
  • 비고란 입력 가능
  • XLSX 일괄 업로드 지원
과목 점수 연도 과목명 달성도

학번, 과목, 달성도 헤더를 가진 xlsx 파일을 업로드하세요.

예: 학번, 1_활력징후, 2_경구투약 형식으로 입력 가능합니다.

업로드하는 모든 점수에 동일한 연도와 과목명이 적용됩니다.
